# 🐍 Snake Game

A simple and fun **Snake Game** built to demonstrate basic game logic, user interaction, and real-time updates. The player controls a snake that grows in length by eating food while avoiding collisions with walls and itself.

---

## 🎮 Game Features

- Classic Snake gameplay  
- Smooth movement controls  
- Snake grows after eating food  
- Score tracking  
- Game over on wall or self-collision  
- Simple and beginner-friendly implementation
